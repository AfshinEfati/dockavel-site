PROJECT PRODUCTIVITY

Smart project workflows without hidden automation

Dockavel can inspect an existing project, suggest the right runtime and services, check a registered project end to end, and handle common local database tasks without requiring Docker commands.

CURRENTRead-only detectionProject healthDatabase helpers
●
Suggestions stay suggestions

Smart detection never silently changes project metadata. project:add still asks before values are saved.

Inspect a project before registering it

bashread-only
dockavel project:detect my-api
# shortcut
dpd my-api

Dockavel reads project files such as composer.json, package.json, lockfiles and .env/.env.example. It can report Laravel or Node type, the PHP requirement, an enabled PHP runtime suggestion, package manager, database hint, Redis hint and whether frontend Node tooling is present.

Example

terminaldetection
Type                     Laravel
PHP requirement          ^8.5
Suggested PHP            8.5
Node frontend            true
Package manager          npm
Database hint            postgres
Redis hint               yes

Check a registered project

bashread-only
dockavel project:check my-api
# shortcut
dpc my-api

The project check validates metadata, source path, project markers, selected runtime, bind-mount visibility, generated Nginx config, Nginx validation, database presence and optional Redis/Node services.

Database helpers

Database helpers use the database selected in .dockavel.yml and the database name from the project's .env (with .env.example as fallback).

ShortcutFull commandPurpose
dbs my-apidockavel db:status my-apiCheck service/database presence
dbc my-apidockavel db:create my-apiCreate the database if missing
dbx my-api backup.sqldockavel db:export my-api backup.sqlExport MySQL/PostgreSQL
dbi my-api backup.sqldockavel db:import my-api backup.sqlImport SQL after confirmation
✓
Conservative database behavior

Export refuses to overwrite an existing file. Import requires explicit confirmation. There is no automatic database drop/reset command in this workflow.

Doctor improvements

ddoc remains read-only and now also surfaces registered project counts, stale registrations, shell proxy variables and a Docker client proxies block when detected.

bashdiagnostics
ddoc
dpc my-api

Version and changelog foundation

bashversion
dockavel version
dockavel --version
dv

The repository keeps a VERSION file and CHANGELOG.md. A development version does not imply that a public GitHub Release or stable tag has already been published.

بهره‌وری پروژه

Workflowهای هوشمند بدون Automation مخفی

Dockavel می‌تواند پروژه موجود را بررسی کند، runtime و سرویس مناسب را پیشنهاد بدهد، سلامت یک پروژه ثبت‌شده را از ابتدا تا انتها چک کند و کارهای رایج دیتابیس local را بدون نیاز به حفظ کردن دستورهای Docker انجام دهد.

فعالDetection فقط خواندنیProject HealthDatabase Helpers
●
پیشنهاد، فقط پیشنهاد می‌ماند

Smart Detection هیچ‌وقت metadata پروژه را مخفیانه تغییر نمی‌دهد. project:add همچنان قبل از ذخیره از کاربر سؤال می‌کند.

بررسی پروژه قبل از Register

bashread-only
dockavel project:detect my-api
# shortcut
dpd my-api

Dockavel فایل‌هایی مثل composer.json، package.json، lockfileها و .env/.env.example را می‌خواند. خروجی می‌تواند نوع Laravel یا Node، نیازمندی PHP، PHP پیشنهادی از بین runtimeهای فعال، package manager، دیتابیس، Redis و وجود ابزارهای frontend Node را نشان بدهد.

نمونه

terminaldetection

بررسی سلامت پروژه ثبت‌شده

bashread-only
dockavel project:check my-api
# shortcut
dpc my-api

این دستور metadata، مسیر سورس، markerهای پروژه، runtime انتخاب‌شده، دیده شدن bind mount داخل container، Nginx config تولیدشده، اعتبار Nginx، وجود دیتابیس و سرویس‌های اختیاری Redis/Node را بررسی می‌کند.

Database Helperها

این دستورها نوع دیتابیس را از .dockavel.yml و نام دیتابیس را از .env پروژه می‌گیرند؛ در صورت نبود آن از .env.example استفاده می‌شود.

Shortcutدستور کاملکاربرد
dbs my-apidockavel db:status my-apiبررسی سرویس و وجود دیتابیس
dbc my-apidockavel db:create my-apiساخت دیتابیس در صورت نبود
dbx my-api backup.sqldockavel db:export my-api backup.sqlExport از MySQL/PostgreSQL
dbi my-api backup.sqldockavel db:import my-api backup.sqlImport بعد از تأیید صریح
✓
رفتار محافظه‌کارانه دیتابیس

Export فایل موجود را overwrite نمی‌کند. Import تأیید صریح می‌خواهد. در این workflow هیچ دستور خودکار Drop/Reset اضافه نشده است.
