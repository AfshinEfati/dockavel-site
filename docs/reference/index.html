Dockavel CLI

After ./dockavel shortcuts:install or shortcut installation during setup, dockavel works globally. The original ./dockavel ... forms remain valid before or after installation.

CommandShortcutPurpose
dockavel doctorddocRead-only environment, network and stack diagnostics
dockavel source:testdsrcTest the download endpoints currently configured in .env
dockavel project:adddpaRegister an existing Laravel or Node.js project
dockavel project:listdplList registered projects and runtime/database mapping
dockavel project:edit [project]dpe [project]Edit project registration and regenerate Nginx safely
dockavel project:remove [project]dpr [project]Remove Dockavel registration without deleting source
dockavel shell <project>ds <project>Open a shell in the project's configured runtime
dockavel artisan <project> [args...]da <project> [args...]Run Laravel Artisan in the configured PHP runtime
dockavel composer <project> [args...]dco <project> [args...]Run Composer in the configured PHP runtime
dockavel npm <project> [args...]dn <project> [args...]Run npm in the shared Node runtime for a Node-enabled project
dockavel help [command]dh [command]Show full CLI help or one command topic

Shortcut management

bashglobal CLI
./dockavel shortcuts:install
dockavel shortcuts:list
dockavel shortcuts:install
dockavel shortcuts:remove

Managed symlinks are installed in ~/.local/bin. Existing commands/files are never overwritten. Dockavel uses ddoc instead of dd because dd is a standard Unix command.

Dockavel CLI

بعد از ./dockavel shortcuts:install یا انتخاب نصب shortcutها در setup، دستور dockavel به‌صورت global کار می‌کند. فرم‌های قدیمی ./dockavel ... هم همچنان معتبر هستند.

دستورShortcutکاربرد
dockavel doctorddocDiagnostics read-only برای محیط، شبکه و استک
dockavel source:testdsrcتست endpointهای دانلود تنظیم‌شده در .env
dockavel project:adddpaثبت پروژه Laravel یا Node.js موجود
dockavel project:listdplنمایش پروژه‌ها و mapping runtime/database
dockavel project:edit [project]dpe [project]ویرایش registration و تولید امن Nginx
dockavel project:remove [project]dpr [project]حذف registration بدون حذف سورس
dockavel shell <project>ds <project>باز کردن shell داخل runtime پروژه
dockavel artisan <project> [args...]da <project> [args...]اجرای Artisan داخل PHP runtime پروژه
dockavel composer <project> [args...]dco <project> [args...]اجرای Composer داخل PHP runtime پروژه
dockavel npm <project> [args...]dn <project> [args...]اجرای npm داخل Node مشترک برای پروژه Node-enabled
dockavel help [command]dh [command]نمایش Help کامل یا Help یک command

مدیریت Shortcutها

bashglobal CLI
./dockavel shortcuts:install
dockavel shortcuts:list
dockavel shortcuts:install
dockavel shortcuts:remove

symlinkهای مدیریت‌شده داخل ~/.local/bin نصب می‌شوند و هیچ command یا فایل موجودی overwrite نمی‌شود. از ddoc به‌جای dd استفاده شده چون dd یک command استاندارد Unix است.
