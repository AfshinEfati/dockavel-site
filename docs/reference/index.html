Commands, environment and project files

A compact reference for the current Dockavel CLI, Compose services, important environment values, machine-local files and the next planned command layer.

Dockavel CLI

CommandPurpose
./dockavel doctorRead-only system, network and stack diagnostics
./dockavel source:testTest currently configured download endpoints
./dockavel project:addRegister an existing Laravel or Node project
./dockavel project:listList registered projects and runtime/database mapping
./dockavel project:edit [name]Edit project registration and regenerate Nginx safely
./dockavel project:remove [name]Remove Dockavel registration without deleting project source
./dockavel helpShow CLI help

CI coverage

  • Multiple Compose profile combinations
  • PHP 8.2, 8.3, 8.4 and 8.5 builds
  • Required PHP runtime capabilities
  • Node.js 24 build/runtime
  • Shell syntax for setup, CLI and Project Manager
  • Executable CLI entry point

Roadmap

The current foundation already includes configurable stack setup, multiple PHP runtimes, regional sources, shared MySQL/PostgreSQL/Redis/Node services, Doctor/source diagnostics and Project Manager add/list/edit/remove.

→
Planned, not current commands

The next productivity layer will use project metadata to route everyday commands to the correct runtime.

plannednot released yet
./dockavel shell my-api
./dockavel artisan my-api migrate
./dockavel composer my-api install
./dockavel npm frontend install

Design principle

A feature belongs in the Dockavel core when it speeds up project setup, simplifies multi-project management, or reduces local-environment errors and debugging. The goal is more capability, not more configuration.

Roadmap

Foundation فعلی شامل setup قابل تنظیم، چند PHP، sourceهای منطقه‌ای، سرویس‌های مشترک MySQL/PostgreSQL/Redis/Node، Doctor/source diagnostics و Project Manager کامل add/list/edit/remove است.

اصل طراحی Dockavel

یک قابلیت وقتی وارد core می‌شود که setup پروژه را سریع‌تر کند، مدیریت چند پروژه را ساده‌تر کند یا خطا و debugging محیط local را کم کند. هدف «قابلیت بیشتر» است، نه «تنظیمات بیشتر».
