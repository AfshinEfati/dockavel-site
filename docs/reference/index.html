REFERENCE

CLI, shortcuts and stack reference

Compact reference for the current Dockavel project workflow, database helpers, diagnostics, services and ports.

CLI commands

CommandShortcutPurpose
dockavel project:adddpaRegister an existing Laravel or Node.js project
dockavel project:listdplList registered projects
dockavel project:edit [project]dpeEdit registration and regenerate Nginx safely
dockavel project:remove [project]dprRemove registration without deleting source
dockavel project:detect <directory>dpdRead-only project/runtime/service suggestions
dockavel project:check <project>dpcRead-only project health check
dockavel shell <project>dsOpen the configured project runtime shell
dockavel artisan <project> [args...]daRun Artisan in the configured PHP runtime
dockavel composer <project> [args...]dcoRun Composer in the configured PHP runtime
dockavel npm <project> [args...]dnRun npm in the shared Node runtime
dockavel db:status <project>dbsCheck configured database presence
dockavel db:create <project>dbcCreate configured database if missing
dockavel db:export <project> [file.sql]dbxExport without overwriting an existing file
dockavel db:import <project> <file.sql>dbiImport SQL after explicit confirmation
dockavel doctorddocRead-only environment, proxy, project and stack diagnostics
dockavel source:testdsrcTest configured download sources
dockavel versiondvShow Dockavel version
dockavel help [command]dhShow full or topic help
→

Global CLI

bashone-time
./dockavel shortcuts:install
dockavel shortcuts:list
dockavel shortcuts:remove

Managed links live in ~/.local/bin. Existing commands/files are not overwritten.
