STACK & RUNTIMES

One stack, only the services you enable

Dockavel uses Docker Compose profiles to keep the core focused. Multiple PHP versions can run together, shared services are optional, and Nginx stays the local gateway.

PHP runtimes

All four PHP runtimes are built locally from the public serversideup/php:<version>-fpm upstream image through the selected Docker namespace/mirror.

upstream examplespublic images
serversideup/php:8.2-fpm
serversideup/php:8.3-fpm
serversideup/php:8.4-fpm
serversideup/php:8.5-fpm

Every enabled PHP runtime mounts ./projects at /var/www. Different projects can therefore use different PHP services while sharing the same workspace.

Nginx routingexample
old-app.local  -> php82:9000
api.local      -> php84:9000
new-app.local  -> php85:9000

Service, container and image names

PHP 8.5naming
Compose service : php85
Container name  : dockavel-php85
Local image     : dev-stack-php85

For normal commands, prefer the Compose service name:

bashrecommended
docker compose exec php85 bash
docker compose exec php85 php -v

Node.js

The shared Node.js 24 runtime is built locally from the public node:24-bookworm-slim image through the selected Docker library mirror and mounts the same projects/ directory.

bashruntime
docker compose exec node node --version
docker compose exec node npm --version

docker compose exec node bash
cd /var/www/frontend
npm install

Node projects registered through Project Manager use internal application ports in the 3000-3099 range and are exposed through Nginx.

Database UIs

phpMyAdmin

When mysql-ui is enabled, open http://127.0.0.1:18080 and use mysql as the server host.

pgAdmin

When postgres-ui is enabled, open http://127.0.0.1:18081 and register postgres:5432. Data persists in pgadmin_data.

استک و Runtimeها

یک استک، فقط سرویس‌هایی که فعال می‌کنی

Dockavel با Docker Compose profileها core را جمع‌وجور نگه می‌دارد. چند PHP می‌توانند کنار هم اجرا شوند، سرویس‌های مشترک اختیاری‌اند و Nginx gateway اصلی local باقی می‌ماند.

PHP Runtimeها

هر چهار PHP به‌صورت local از image عمومی serversideup/php:<version>-fpm و از طریق Docker namespace/mirror انتخاب‌شده build می‌شوند.

upstream examplespublic images
serversideup/php:8.2-fpm
serversideup/php:8.3-fpm
serversideup/php:8.4-fpm
serversideup/php:8.5-fpm

همه PHPهای فعال، ./projects را روی /var/www mount می‌کنند. بنابراین پروژه‌ها workspace مشترک دارند ولی runtime متفاوت.

Nginx routingexample
old-app.local  -> php82:9000
api.local      -> php84:9000
new-app.local  -> php85:9000

تفاوت service، container و image

PHP 8.5naming
Compose service : php85
Container name  : dockavel-php85
Local image     : dev-stack-php85

برای استفاده عادی، اسم Compose service بهتر است:

bashrecommended
docker compose exec php85 bash
docker compose exec php85 php -v

Node.js

Node.js 24 مشترک از image عمومی node:24-bookworm-slim و از طریق Docker library mirror انتخاب‌شده local build می‌شود و همان پوشه projects/ را mount می‌کند.

bashruntime
docker compose exec node node --version
docker compose exec node npm --version

docker compose exec node bash
cd /var/www/frontend
npm install

پروژه‌های Node ثبت‌شده در Project Manager از پورت داخلی محدوده 3000-3099 استفاده می‌کنند و از Nginx بیرون می‌آیند.

ابزارهای دیتابیس

phpMyAdmin

با profile mysql-ui روی http://127.0.0.1:18080 باز می‌شود و host دیتابیس mysql است.

pgAdmin

با profile postgres-ui روی http://127.0.0.1:18081 باز می‌شود. PostgreSQL را با postgres:5432 ثبت کن. داده‌ها در pgadmin_data می‌مانند.
