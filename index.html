Why Dockavel?

Your local stack should help you ship, not become another project.

Dockavel keeps the useful automation and leaves the configuration maze behind.

01

Different runtimes, one workspace

Run PHP 8.2 and PHP 8.5 side by side without cloning an entire infrastructure stack per project.

legacy.local→php82:9000
api.local→php85:9000
02

Networks are not always reliable

Use explicit regional mirrors and diagnose Docker, Debian, Composer, npm, DNS and route problems without hidden fallbacks.

Composer200 ✓
03

Projects should know their runtime

Keep tiny per-project metadata and let Dockavel generate routing instead of memorizing container names.

Core capabilities

Useful automation. Small surface area.

Dockavel stays opinionated: features belong in the core when they make setup faster, project management simpler, or debugging easier.

>_
PROJECT MANAGER

Register, edit, list and remove projects

Dockavel detects Laravel or Node.js, stores minimal metadata, generates Nginx config, validates it and reloads safely.

./dockavel project:add ./dockavel project:edit booking-api ./dockavel project:remove booking-api
8.x
MULTI-RUNTIME

PHP 8.2 → 8.5 together

Enable only the versions you need. Nginx routes each local domain to the correct FPM service.

◎
DIAGNOSTICS

Doctor that does not “fix” behind your back

Read-only checks for Docker, WSL, ports, stack health and source connectivity, including IPv4-route hints.

REGIONAL SOURCES

Explicit download sources

Official, IranServer, Runflare, China or custom endpoints. A regional preset does not silently fall back elsewhere.

SHARED SERVICES

Only what the project needs

MySQL, PostgreSQL, Redis, Node.js, phpMyAdmin and pgAdmin are optional Compose profiles.

Project-aware by design

Tiny metadata. Predictable routing.

Each registered project keeps just enough information for Dockavel to understand its domain, runtime and shared services.

✓No giant project configuration file

✓Rollback when generated config fails

Quick start

From clone to local stack in a few commands.

The installer handles source selection, runtimes, databases and optional services interactively.

Read the installation guide →
bash
$ git clone https://github.com/AfshinEfati/dockavel.git
$ cd dockavel
$ chmod +x setup.sh dockavel
$ ./setup.sh

# after setup
$ ./dockavel doctor
$ ./dockavel project:add
